# Changelog

Notable changes to Font Size Tweak are documented here.

## v1.1.0

- Added a persistent backup of the user's original supported font settings.
- Added restore actions for the selected setting or all original settings.
- Added one-level undo for the most recent apply or restore operation.
- Added current and proposed value display.
- Added exact, synchronized numeric and slider controls.
- Refined the interface into a more compact layout.
- Improved registry validation, error handling and partial-failure feedback.

## v1.0.0

- Initial stable release.
