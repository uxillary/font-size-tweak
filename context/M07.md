# M07 — Organic discovery tools and comparison research

## Implementation

- Added `/guides/which-windows-sizing-setting/` as an interactive Windows sizing decision tool.
- The tool uses semantic radio inputs, minimal vanilla JavaScript and dedicated CSS. Its explanatory recommendation reference remains visible without JavaScript; in that case the initial static recommendation is Windows Text size.
- Decision mappings recommend Windows Text size for broad text needs; Display scaling for the whole interface; Text size first, then the relevant Icons, Menus, Title Bar or Message Boxes metric for those targeted categories; Status Bar for compatible legacy status text; and Text size as a starting point when unsure.
- Added result announcements through an atomic polite live region, focus visibility, keyboard-native radio operation, responsive layouts and reduced-motion-compatible styles. No animation was introduced.
- Added a card on the Guides hub and a sitemap entry. Existing guides already link to the relevant sizing comparison, File Explorer and troubleshooting resources; the new tool links back to each as appropriate. The homepage was left unchanged apart from removing an unsupported competitor-comparison FAQ claim.

## Comparison research

- Repository search found existing Advanced System Font Changer references in the root homepage, roadmap and FAQ structured data. The roadmap is internal planning, not deployed-site content.
- Font Size Tweak facts were checked against `main.py`, `README.md`, `context/project.md` and the existing website: it adjusts CaptionFont, MenuFont, MessageFont, IconFont and StatusFont in the current user's WindowMetrics settings, preserving the raw font data while changing its height field. It is free, MIT licensed and public source; compatibility varies by component/build.
- Search found the developer's official WinTools.Info Advanced System Font Changer page and official family documentation. The official product page could not be fetched during this research session (cache miss). Without readable primary-source evidence for the comparison dimensions requested, no comparison page was published, and claims about competitor features, add-ons, compatibility, portability, licensing or recovery were omitted. The unsupported homepage FAQ comparison claim was removed.

## M07B — Font Size Tweak vs Advanced System Font Changer

The comparison evidence supplied for M07B was independently checked against first-party WinTools.Info sources on 5 October 2026. This resolves the evidence limitation recorded above; the earlier M07A research history is retained.

- Comparison URL: `/guides/font-size-tweak-vs-advanced-system-font-changer/`.
- Competitor sources: [official product page](https://www.wintools.info/index.php/advanced-system-font-changer), [official comparison table](https://www.wintools.info/index.php/windows-10-system-font-settings-comparison-table), [changelog](https://www.wintools.info/index.php/advanced-system-font-changer-changelog), [terms of use](https://www.wintools.info/index.php/windows-10-system-font-settings-terms-of-use), [usage guide](https://www.wintools.info/index.php/windows-10-system-font-settings-usage), [removal guide](https://www.wintools.info/index.php/windows-10-system-font-settings-removal), and [known issues](https://www.wintools.info/index.php/windows-10-system-font-settings-known-issues).

WinTools documents WindowMetrics backup/restore data and restoration options. Its terms say activation is required after a 30-day trial.
- Font Size Tweak claims were verified in `main.py`, `README.md` and `LICENSE`: five metrics (Title Bar/CaptionFont, Menus/MenuFont, Message Boxes/MessageFont, Icons/IconFont, Status Bar/StatusFont); Quick Adjustment or individual 8–16 pt sizing; size-only controls; current/proposed values and sample preview; persistent capture of original settings, selected/all restore, one-level in-session undo; Windows 10/11; portable executable; free and MIT licensed.
- Licensing wording on-page is “Free and open source under the MIT licence” versus “30-day trial; activation is required for continued use.” Current activation pricing is omitted and readers are directed to the official terms for current pricing/activation details.
- Compatibility wording states that neither utility controls all interfaces and that visible behavior can vary by Windows version, component and application. WinTools' own unsupported-properties warning is attributed without using it to make an attack or an unverified head-to-head compatibility claim.

Font Size Tweak is described as the focused, free, inspectable size-only option. Both are described as not requiring conventional installation based on product documentation; this is not positioned as a unique advantage.

Internal links connect the comparison to the decision tool and troubleshooting guide. The decision tool now offers the comparison from its specific classic-metric results.
