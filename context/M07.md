# M07 — Organic discovery tools and comparison research

## Implementation

- Added `/guides/which-windows-sizing-setting/` as an interactive Windows sizing decision tool.
- The tool uses semantic radio inputs, minimal vanilla JavaScript and dedicated CSS. Its explanatory recommendation reference remains visible without JavaScript; in that case the initial static recommendation is Windows Text size.
- Decision mappings recommend Windows Text size for broad text needs; Display scaling for the whole interface; Text size first, then the relevant Icons, Menus, Title Bar or Message Boxes metric for those targeted categories; Status Bar for compatible legacy status text; and Text size as a starting point when unsure.
- Added result announcements through an atomic polite live region, focus visibility, keyboard-native radio operation, responsive layouts and reduced-motion-compatible styles. No animation was introduced.
- Added a card on the Guides hub and a sitemap entry. Existing guides already link to the relevant sizing comparison, File Explorer and troubleshooting resources; the new tool links back to each as appropriate. The homepage was left unchanged apart from removing an unsupported competitor-comparison FAQ claim.

## Comparison research

- Repository search found existing Advanced System Font Changer references in the root homepage, roadmap and FAQ structured data. The roadmap is internal planning, not deployed-site content.
- Font Size Tweak facts were checked against `main.py`, `README.md`, `context/project.md` and the existing website: it adjusts CaptionFont, MenuFont, MessageFont, IconFont and StatusFont in the current user's WindowMetrics settings, preserving the raw font data while changing its height field. It is free, MIT licensed and public source; compatibility varies by component/build.
- Search found the developer's official WinTools.Info Advanced System Font Changer page and official family documentation. The official product page could not be fetched during this research session (cache miss). Without readable primary-source evidence for the comparison dimensions requested, no comparison page was published, and claims about competitor features, add-ons, compatibility, portability, licensing or recovery were omitted. The unsupported homepage FAQ comparison claim was removed.
