Windows 11 · File Explorer

Make File Explorer and folder-name text larger

If file and folder names are hard to read, first try Windows’ text-size setting. If you need more targeted control over supported classic labels, Font Size Tweak can adjust the label font metric without enlarging the icon graphics.

Try Windows Text size first

In Windows 11, open Settings → Accessibility → Text size. Move the slider until the sample is comfortable, select Apply, then check File Explorer and other apps you use. This is a built-in way to make text larger without changing the display’s scale.

Text-size support can vary between apps and interface components. If the file and folder labels you care about remain too small, compare this setting with display scaling before deciding which trade-off suits your screen.

Text size and display scaling change different things

  • Accessibility → Text size enlarges text in Windows and apps that honor that setting.
  • Settings → System → Display → Scale scales more of the interface, including text, controls and layout. It may make the whole desktop feel larger.
  • Font Size Tweak adjusts selected classic Windows font metrics for the current user. It can offer more targeted control where a component uses those metrics.

For a high-resolution display, Windows scaling may be the most comfortable option if many interface elements are too small. If the overall layout already feels right and only particular text needs adjustment, try the text-size setting first; a supported classic metric may offer a narrower adjustment for some labels.

For a fuller comparison of the Windows options, read Windows text size vs display scaling.

Adjust supported file and folder labels

Font Size Tweak’s Icons control changes the classic Windows IconFont metric. That metric is used by desktop icon labels and supported File Explorer file and folder labels on compatible Windows builds. It changes label text size; it does not resize the icon graphics.

  1. Download the latest free release and extract the downloaded archive.
  2. Run FontSizeTweak.exe. The portable app does not require installation or administrator access.
  3. Under Individual Adjustment, choose Icons, set a comfortable size using the available controls, and apply it.
  4. Check the labels that matter to you. Sign out of Windows and back in if a compatible interface has not refreshed.

The app keeps a backup of the original values captured before its first change. Its restore action returns those captured settings; it does not assume or write hard-coded Microsoft defaults.

What it changes—and what it cannot

The app updates the current user’s classic font metrics for title bars, menus, message boxes, icons and status bars. Windows also has newer and app-specific interfaces that do not use these metrics. File Explorer behavior can vary across Windows components and builds, so the Icons setting will not necessarily change every label everywhere.

Font Size Tweak changes font size only. It does not change font family, boldness, icon graphics, app-specific text settings or display scaling.

If the labels do not look different

  • Confirm you adjusted Icons, then apply the change.
  • Sign out of Windows and back in to refresh interfaces that have not picked up the new value.
  • Check more than one compatible label. A modern or custom-rendered component may not use the classic metric.
  • If the overall desktop is too small, review Windows display scaling; changing a font metric does not resize controls or layout.
