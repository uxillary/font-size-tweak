Font Size Tweak vs Advanced System Font Changer

Both utilities expose classic Windows system-font settings that the usual Windows controls do not offer individually. Font Size Tweak focuses on five independent size metrics; Advanced System Font Changer offers more detailed configuration, styles, profiles and hotkey switching. Which fits depends on the control you need.

Consider this if

Font Size Tweak

It may suit you if you want to adjust supported classic font sizes individually, prefer a focused workflow, or require free and inspectable MIT-licensed software.

  • Five controls: Title Bar, Menus, Message Boxes, Icons and Status Bar.
  • Apply one size to all five or adjust a metric individually.
  • Original-settings restore and one-level undo are built in.
Free download

Consider this if

Advanced System Font Changer

It may suit you if you want more extensive font configuration, different size and style choices for individual system fonts, or profiles that you can switch with hotkeys.

  • More detailed configuration than a size-only control set.
  • Profiles and hotkey profile switching.
  • Trial use, with activation required to continue afterward.
Official product page

You may not need either utility

If you want text broadly larger across Windows, start with Windows Accessibility → Text size. If the whole interface—including controls and spacing—feels too small, try Settings → System → Display → Scale. These built-in options may be a better fit than changing classic font metrics.

Use the Windows sizing decision tool to choose a starting point, or read Text size vs display scaling for a fuller explanation.

Compatibility depends on the interface

Both tools work with classic Windows system-font properties. WinTools says these properties are not officially supported by Microsoft and that behavior can vary across Windows versions, computers and applications. It also documents that some modern Windows components may not use them. Font Size Tweak has the same practical limitation: newer or custom-rendered UI may ignore classic metrics. Neither utility should be expected to change every Windows screen or app.

Test the specific interface you care about. A component may need to be restarted or Windows may need a sign-out before compatible text refreshes. If a change does not appear, see Windows font-size changes not appearing.
