Windows text size vs display scaling

If you want text to be easier to read but do not want every window and control to grow, start with Windows’ Accessibility → Text size setting. Use Display → Scale when the whole interface is too small. Font Size Tweak offers a narrower adjustment for supported classic Windows font categories.

Make text broadly larger with Accessibility → Text size

Windows 11’s built-in Text size control is a sensible first choice when text across Windows is difficult to read. It is an accessibility setting designed to enlarge text without changing display resolution or scaling the whole interface. The text-size setting can affect areas such as title bars, menus and icon text; individual apps and components may respond differently.

  1. Open Settings → Accessibility → Text size. You can also press Windows logo key + U to open Accessibility settings.
  2. Move the Text size slider to the right and review the sample.
  3. Select Apply, then check the apps and Windows areas where you wanted larger text.

This is often the best place to begin if you simply want text broadly larger. It is built into Windows and does not require a separate utility. See Microsoft’s Windows text and app size instructions for the current steps.

Make the whole interface larger with Display → Scale

Display scaling enlarges more than text: it scales apps and many other interface elements, including controls and layout. This can be the right choice when the entire interface feels too small, especially on a high-resolution 4K display or a physically small high-DPI laptop screen.

  1. Open Settings → System → Display. If you use more than one display, select the display you want to adjust.
  2. Under Scale & layout, open Scale and choose an option. Windows marks a recommended value for the display.
  3. Review your apps and workspace. Some apps may need you to sign out and back in before the change takes effect.

Scaling is not a bad setting; it solves a broader sizing problem. The trade-off is that windows, controls and workspace can all take up more screen space. If those already feel comfortable and only certain text is too small, a broader scale change may be more than you need. Microsoft’s display scaling guidance explains the Scale setting.

Font metrics

Best suited to: adjusting supported classic Windows font categories independently.

Changes: title bars, menus, some message boxes, desktop/supported Explorer labels and compatible status text.

Consider when: particular supported text needs a different size while the broader layout is comfortable.

Which one fits your situation?

  • “My entire 4K display is too small.” Try Display → Scale first; Windows’ recommended value is a useful starting point.
  • “Text across Windows is difficult to read.” Try Accessibility → Text size first.
  • “File and folder labels are too small, but everything else is comfortable.” Font Size Tweak’s Icons metric can adjust supported label text without resizing icon graphics. See the File Explorer text-size guide for steps and limitations.
  • “Menus or title text need to be larger, but I like my current layout.” Font Size Tweak exposes separate supported metrics for menus and title bars. Some modern or app-specific elements may not use them.

Where Font Size Tweak fits

Font Size Tweak changes five per-user classic Windows font metrics: Title Bar, Menus, Message Boxes, Icons and Status Bar. This is a more targeted level of control for those categories; it does not change general display scaling or replace Windows accessibility settings.

Not every control, dialog or application uses these classic metrics. Results vary between Windows components and builds, and signing out and back in may be needed for compatible areas to refresh. The app changes font size only, not font family, boldness, icon graphics or app-specific text settings.
