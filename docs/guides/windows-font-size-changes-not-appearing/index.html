Windows font-size changes not appearing

First confirm that you changed and applied the right setting. Some compatible Windows interfaces update straight away; others need you to sign out and back in. A modern or custom-rendered component may not use the classic font metric you changed at all.

Work through these checks in order

  1. Confirm the setting was applied. For Windows Accessibility → Text size, move the slider and select Apply. For Display → Scale, check that you changed the intended display. In Font Size Tweak, look for its saved/status message after choosing a size and applying it.
  2. Check which Font Size Tweak metric you changed. The five controls affect different categories. If you changed Icons but expected menu text to change, choose Menus instead. Use the reference below.
  3. Check whether the affected interface uses that metric. Classic Windows components may use these settings; newer Windows UI and applications that draw their own text may not. Test a compatible area before concluding the app failed.
  4. Give the interface a chance to refresh. Some changes may appear immediately. If the affected area still looks the same, sign out of Windows and sign back in, then check again. The app documentation recommends this for compatible interfaces that do not refresh immediately.
  5. Choose a broader Windows setting if that better matches the problem. For text across Windows, try Accessibility → Text size. If the whole interface is too small, consider Display → Scale.
  6. Restore captured settings if you want to undo the app’s change. Use Restore for the selected metric or restore all original settings; see the restore section below.

A sign-out can refresh compatible UI, but it cannot make a component use a font metric it ignores. The repository documentation does not establish that restarting Explorer or rebooting Windows is required.

Match the control to the text

Font Size Tweak changes five classic, per-user Windows font metrics. These are the areas each control is intended to affect; a particular app or component may not use the metric.

Title Bar
Classic window title text, such as title bars in Notepad and Explorer.
Menus
Classic menu bars and right-click menus.
Message Boxes
Some classic message dialogs and prompts.
Icons
Desktop icon labels and supported File Explorer file/folder labels. This changes label text, not icon graphics.
Status Bar
Status text in compatible legacy interfaces.

For example, if Explorer file and folder names are the concern, the Icons metric is the relevant control on supported builds. The File Explorer text-size guide explains the Windows options and app steps in more detail.

Why a correctly applied change may still have no effect

Font Size Tweak edits classic font metrics in the current Windows user’s settings. Newer Windows interfaces can use different rendering systems, and individual applications can draw their own text. Those components may ignore these metrics even after you sign out and sign back in.

Behavior can differ by component and Windows build. That means no visible change in one dialog does not by itself show that the app failed; it may mean that dialog does not use the selected metric. The app is not a universal font controller, and its changes do not resize icon graphics, app layouts or display scaling.

Quick distinction: if compatible classic text changes after applying and signing back in, the setting took effect. If only one modern or custom app ignores it, that component may use its own text rendering. If text broadly needs to be larger, use Windows’ own sizing controls.

When another setting is a better fit

  • “I changed Icons but menu text did not change.” Menus is the relevant Font Size Tweak metric for classic menus.
  • “The icon pictures stayed the same size.” That is expected: the Icons metric affects supported label text, not icon graphics.
  • “Everything on my 4K display is tiny.” Display → Scale may be a better fit because it enlarges apps and more of the interface, not just supported text.
  • “Text throughout Windows is difficult to read.” Try the built-in Accessibility → Text size setting first.

For a step-by-step comparison, see Windows text size vs display scaling.

Restore the settings Font Size Tweak captured

If you no longer want a change, are unsure which metric caused an unwanted result, or want to return to the state captured by the app, use Restore for the selected metric or Restore Original Settings for all five.

Font Size Tweak saves the original values it captures before its first registry change. Restore writes those saved values back; it does not guess or write assumed Microsoft “default” values. The backup remains in your Windows user profile and is not replaced on later launches.

Undo Last Change is different: it reverses one latest apply or restore operation using an in-memory snapshot. It is one-level and does not survive closing the app.
