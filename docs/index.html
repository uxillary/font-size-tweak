How Font Size Tweak works

Font Size Tweak updates the same registry keys that Windows uses for interface text: HKCU\Control Panel\Desktop\WindowMetrics. The application writes the values when you apply them, and this website never touches your registry.

For best results after changing Windows system font size without scaling, sign out and back in so apps refresh their typography.

Frequently asked questions

Does this replace display scaling?

No. Font Size Tweak lets you change Windows system font size for individual interface elements without altering your global display scaling setting.

Which Windows versions are supported?

The tool targets Windows 11 and Windows 10 desktop releases. Earlier versions may partially work but are not officially supported.

Is it portable and safe to use?

Yes. The executable is portable, digitally unsigned, and open source. It writes only to HKCU\Control Panel\Desktop\WindowMetrics when you apply changes.

Do I need to restart or sign out/in?

Most tweaks apply immediately, but we recommend signing out and back in to ensure every application recognises the new font size.

Can I revert to defaults?

Absolutely. Use the reset button to restore Microsoft defaults for every element.

How is this different from Advanced System Font Changer?

Font Size Tweak focuses on core Windows font controls with an MIT licence, dark mode interface, and zero-cost download. Advanced System Font Changer offers similar controls with commercial add-ons.
