A more precise option

Larger text, not a larger everything

Small Windows text can be uncomfortable on high-DPI displays. You may want to make File Explorer text bigger, increase Windows menu font size, or improve UI legibility without moving the entire interface to 125% or 150% scaling.

Display scaling can enlarge controls, spacing and windows that were already comfortable. Font Size Tweak instead focuses on supported Windows 10 and Windows 11 system font metrics, giving you a narrower adjustment for easier-to-read text.

Under the hood

How it works

Font Size Tweak changes supported font metrics stored for your user account under:

HKEY_CURRENT_USER\Control Panel\Desktop\WindowMetrics

Careful, targeted changes

The tool preserves the existing registry font data and adjusts the relevant font-size metric. It does not change global display scaling.

Some Windows UI elements do not use these legacy system font metrics, so they may not respond.

Known limitations

Windows does not expose every UI font through classic metrics. Newer or differently rendered interfaces may ignore these settings, and results vary between components and Windows builds. Signing out and back in may be required for a complete refresh.

Helpful answers

Frequently asked questions

How do I make File Explorer text bigger in Windows 11?

Open Font Size Tweak, increase the Icon font metric, apply the change, then sign out and back in if Explorer does not refresh immediately.

Can I increase Windows text size without changing display scaling?

Yes. Font Size Tweak changes supported system font metrics while leaving Windows display scaling unchanged.

How do I make Windows menu text larger?

Use the Quick Apply control for all supported metrics or adjust Menu individually in Advanced controls.

Does Font Size Tweak work on Windows 10 and Windows 11?

Yes. Font Size Tweak is intended for Windows 10 and Windows 11, although results can differ between components and Windows builds.

Does Font Size Tweak require administrator access?

No. It changes settings for the current Windows user and does not require administrator access.

Why doesn't every Windows dialog change size?

Not every interface uses the classic Windows font metrics. Newer or custom-rendered components may ignore them.

Is Font Size Tweak free?

Yes. The application is free to download and use under the MIT licence.

Is Font Size Tweak open source?

Yes. Its source code is public on GitHub and can be inspected before running the executable.

How do I restore the original Windows font sizes?

Use the reset function in Font Size Tweak, then sign out and back in if needed to refresh the interface.

Is this an alternative to Advanced System Font Changer?

It is a lightweight, open-source option for adjusting the supported Windows font metrics. Feature sets may differ, so choose the tool that fits your needs.
