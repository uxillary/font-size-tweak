# Font Size Tweak v1.1.0

Font Size Tweak is a free, open-source Windows 10/11 utility for making supported File Explorer, menu, icon, title bar and system UI text easier to read without increasing display scaling.

## Use

Extract the archive and run `FontSizeTweak.exe`. The app is portable, requires no installation or administrator rights, and may require you to sign out and back in before all compatible interfaces refresh.

Font Size Tweak supports Quick Apply and individual controls for title bars, menus, message boxes, icons and status bars. It shows current and proposed sizes, provides exact slider and numeric controls, and reports operation status or errors.

Before the first change, v1.1.0 persistently backs up the user's complete original values for all five supported settings. You can restore one or all of those captured values, or undo the latest apply or restore operation. Restores do not use hard-coded Microsoft defaults.

> Some Windows interfaces use different rendering systems and may not respond to these classic font metrics.
